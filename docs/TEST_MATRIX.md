# Manual test matrix (P6.3)

Each scenario must leave the widget running with the other collectors still working. Record Pass/Fail in Result and the build label (e.g. `3.0.0+a1b2c3d`) in Build.

Run 2026-09-29 by Claude on Steve's laptop (Windows 11, two 1920×1080 displays). The build was a local `dotnet AIStatusBar.dll` run from `claude/phase6-hardening`; it reports `3.0.0+cc227e4` and contains the D18 changes committed in `9fa6047`. Steve's settings, token and state were backed up first and restored afterwards. His real Codex and Claude session files were never modified: file scenarios used temporary data folders seeded with synthetic records.
